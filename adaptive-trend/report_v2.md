## 二、Survivorship Bias 修正方法

### 候選宇宙（固定池，共 30 個幣）

以下均為 2020 年前後已在 Binance USDT 現貨上市的主流幣：

```
BTCUSDT, ETHUSDT, XRPUSDT, BNBUSDT, LTCUSDT, BCHUSDT, ADAUSDT, LINKUSDT,
DOTUSDT, UNIUSDT, SOLUSDT, MATICUSDT, DOGEUSDT, AVAXUSDT, ATOMUSDT,
XLMUSDT, VETUSDT, TRXUSDT, ETCUSDT, FILUSDT, THETAUSDT, ALGOUSDT,
XMRUSDT, ZECUSDT, DASHUSDT, EOSUSDT, XTZUSDT, AAVEUSDT, COMPUSDT, SUSHIUSDT
```

**注意**：SOLUSDT 於 2020-09 才上市；FILUSDT、AAVEUSDT、SUSHIUSDT 於 2020 年下半年上市；這些幣在上市前的月份自動因成交量=0 而被排除，**不會出現回測起點（2020-01）時選入未上市幣的問題**。

### 動態月度宇宙選取邏輯

每個月末，計算所有候選幣該月 6H K線的累計 USDT 成交量（close × volume 之和），：

1. 排除當月成交量 = 0（未上市）的幣種
2. 排除當月日均成交量 < $5,000 萬 USDT 的小流動性幣種
3. 按成交量從大到小排列，取前 20 大為當月投資宇宙

**效果**：2020 年初的宇宙自然為 BTC/ETH/XRP/BNB/LTC/BCH/ADA/ETC/ZEC/DASH/TRX/XLM/ATOM 等早期幣種，不含任何 2021 年以後才爆發的幣。

## 三、策略邏輯（完整版）

### 參數設定

| 參數 | 值 | 說明 |
|------|-----|------|
| ROC 週期 | 20 根 6H 棒 | ≈ 5 天動量 |
| ATR 週期 | 14 根 6H 棒 | ≈ 3.5 天 |
| ATR 乘數 | 2.5 | Trailing Stop 寬鬆度 |
| Sharpe 門檻（多倉） | ≥ 1.3 | 上月月度 Sharpe |
| 多倉最大持倉 | 5 個幣 | 等權重 |
| 空倉最大持倉 | 3 個幣 | 等權重 |
| 多倉配置 | 70% | 有多倉候選時 |
| 空倉配置 | 30% | 有空倉候選時 |
| 現金配置 | 剩餘 | 無候選時閒置 |
| 月度組合止損 | -15% | 觸發後本月不再建倉 |

### 多倉邏輯

上月月度 Sharpe ≥ 1.3 的幣種，取 Sharpe 最高前 5 個。

### 空倉邏輯（v2 重大改進）

**兩個條件同時滿足才啟動**：

1. **BTC 趨勢過濾**：BTC 月初收盤價 < 過去 90 日均線（BTC 處於熊市環境）
2. **排名衰退信號**：幣種上月成交量排名 ≤ 15，本月跌至 16-20（市值衰退訊號）

空倉候選最多取 3 個，等權重配置 30% 資金。

**空倉成本**：
- 手續費：同多倉（按流動性分 4/8/15bps）
- Funding Rate：每 8 小時 0.01%（= 每日 0.03%，年化 10.95%），按持倉天數計算

## 七、空倉活動分析

| 指標 | 數值 |
|------|------|
| 觸發空倉月份 | 3 / 76（3.9%） |
| BTC 熊市月份 | 31 / 76（40.8%） |
| 空倉觸發率（熊市中） | 9.7% |

**觀察**：空倉條件非常嚴格（BTC 熊市 + 排名衰退幣）。在 31 個 BTC 熊市月份中，僅有 3 個月同時存在從 ≤15 排名滑落至 16-20 的幣種。這說明：

1. 市值排名衰退是罕見事件，不頻繁觸發
2. 空倉對整體績效貢獻有限，主要作為保護機制
3. 若要增加空倉利用率，可考慮放寬至「排名從 ≤20 滑落超過 5 名」

## 九、方法論說明：本回測的誠實聲明

1. **Survivorship Bias**：已從「當前 2026 年排名」改為「歷史動態成交量排名」。FILUSDT（2020.10 上市）、SOLUSDT（2020.09 上市）等在其上市前不會出現在宇宙中。
2. **前視偏差（Look-Ahead Bias）**：每月選幣使用「上月完整成交量」排名，不使用當月即時排名，避免前視。
3. **IS/OOS 嚴格隔離**：所有策略參數（ROC=20, ATR=14, Sharpe閾值=1.3, 70/30 配置等）均為先驗設計，OOS 結果出來後未作任何調整。
4. **空倉現實性**：空倉使用永續合約，已計入 Funding Rate 成本。
5. **不足之處**：
   - 實際執行時，排名衰退信號存在滯後（月末才知道當月排名），需提前一個月的排名資料
   - 2026 年部分月份（Jan-Apr）無任何持倉，可能因信號過嚴導致閒置資金過多
   - Sharpe = 0.85 未達研究目標 >1.5，這是誠實的結果
