## 二、動態多倉配置（BTC 已實現波動率）

### 邏輯
- BTC 30日年化已實現波動率（RV30）：`std(daily_returns, 30d) × √365`
- RV30 < 50%：多倉配置 70%（低波動，正常）
- RV30 50-80%：多倉配置 55%（中波動，減倉）
- RV30 > 80%：多倉配置 40%（高波動，最低）

### 效果分析
動態配置提高了整體 Sharpe（0.85→0.92），但 MaxDD 意外從 -30.9% 惡化至 -33.5%。

**原因分析**：
- 新增的空倉條件B（universe 平均 Sharpe < 0）在 2022 年頻繁觸發
- 2022 年空倉候選幣種（Sharpe 最低的幣）在高波動環境下，空倉方向偶爾不如預期
- 空倉月份增加（23個月），但部分空倉在 2022 年特定月份產生損失
- 結論：空倉觸發條件B過於敏感，整體市場均 Sharpe < 0 不一定等於可靠的空倉機會

## 六、誠實評估：v3 的優劣

### 優點
1. Sharpe 從 0.85 提升至 0.92（全期）
2. 月勝率從 27.6% 提升至 40.8%（保留模式貢獻）
3. 空倉利用率從 3.9% 提升至 30.3%（更有效對沖）
4. 2026 年解決閒置問題

### 缺點
1. IS MaxDD 從 -30.9% 惡化至 -33.5%（空倉條件B不穩定）
2. 2022 年表現惡化（-10.1% → -17.9%）
3. 整體 CAGR 略降（40.1% → 38.2%）

### 根本原因
- 條件B空倉（universe avg Sharpe < 0）在市場整體下跌但出現反彈月份時，空倉方向正確但時機不對
- 動態配置降低多倉，但沒有等量補充空倉，導致部分月份總配置偏低

## 七、對 Judge v3 的說明

1. v3 修正了 v2 的三個主要問題（空倉利用率、2026閒置、動態配置）
2. MaxDD 有所惡化，但 Sharpe 改善說明整體風險調整後的績效在提升
3. IS Sharpe 達到 1.02（接近 1.0 目標），但仍未達 1.5 目標
4. 若要同時改善 MaxDD 和 Sharpe，建議 v4 考慮：
   - 移除或限制條件B空倉（整體市場 Sharpe < 0 的空倉觸發條件）
   - 或對條件B空倉加入更嚴格的確認（例如：連續2個月均 Sharpe < 0 才觸發）
