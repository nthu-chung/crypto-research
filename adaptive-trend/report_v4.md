## 一、v4 核心設計（最終版本）

### 整合原則：取 v2 謹慎 + v3 靈活

| 特性 | v2 | v3 | v4（最終）|
|------|-----|-----|---------|
| 多倉門檻 | Sharpe ≥ 1.3 | 同 | 同 |
| 保留模式 | ❌ | ✅ Sharpe ≥ 0.8 + BTC牛市 | ✅（保留）|
| 動態配置 | ❌ 固定70% | ✅ 全時段按RV30 | ✅ 只在熊市動態減倉 |
| 空倉條件A | 排名衰退 | 同 | 同+**需負Sharpe確認** |
| 空倉條件B | ❌ | ✅ 整體Sharpe<0 | ❌（**移除**，噪音太多）|
| Funding Rate | ✅ | ✅ | ✅ |
| 滑點 | 4/8/15bps | 同 | 同 |

### v4 關鍵改進

1. **動態配置只在熊市啟用**（v3問題：牛市高波動時降低配置→錯失牛市漲幅）
   - BTC 牛市：固定 70%，不管 RV30
   - BTC 熊市：按 RV30 動態（70% / 55% / 40%）

2. **移除條件B空倉**（v3問題：整體市場 Sharpe<0 空倉的噪音導致2022惡化）
   - 只保留條件A（排名衰退 ≤15→16-20）
   - 新增確認：空倉候選需同時具有**負Sharpe**（排名衰退且趨勢下行）

3. **保留模式（來自v3）**：無主要候選時，Sharpe ≥ 0.8 + BTC牛市 → 42% 配置

## 三、策略最終版本說明

### 多倉邏輯
1. 計算當月動態成交量宇宙（前20大，日均成交量≥$5000萬）
2. 計算上月各幣種月度 Sharpe 比率
3. **主模式**：Sharpe ≥ 1.3，取前5，配置 70%（牛市）/ 動態（熊市）
4. **保留模式**：無主模式候選 + BTC牛市 + 有 Sharpe ≥ 0.8 幣種 → 取前2，配置 42%
5. ATR Trailing Stop（ATR×2.5）中途止損

### 空倉邏輯（最終版）
- **條件**（同時滿足三個）：
  1. BTC < 90日移動平均（熊市環境）
  2. 幣種上月成交量排名從 ≤15 滑落至 16-20（市值衰退）
  3. 幣種上月 Sharpe < 0（趨勢下行確認）
- **成本**：0.01%/8h Funding Rate + 差異化手續費
- **配置**：最多3個幣，各等權重，總30%

### 多倉配置
- BTC 牛市（BTC > 90日MA）：固定 70%
- BTC 熊市 + RV30 < 50%：70%
- BTC 熊市 + RV30 50-80%：55%
- BTC 熊市 + RV30 > 80%：40%
