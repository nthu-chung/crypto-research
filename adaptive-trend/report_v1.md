## 問題與局限

### 1. 潛在過擬合風險（⚠️ 高優先）
- 宇宙固定為「當前」前 20 大市值幣，**非真正的歷史動態宇宙**
- 實際上應每月重新取當月排名，但 API 不提供歷史市值資料
- 這引入 **survivorship bias**：2020-2021 年用到了當今仍存在的幣（如 SOL, DOGE）
- SOL 自 2020 年 8 月才上市，EDEN 等更晚，但這些幣被納入早期回測

### 2. 交易成本可能低估
- 使用 4bps taker fee，但實際流動性差的小幣（ZEC, SPK 等）滑點可能更高
- 每月換倉 72 次，但 ATR stop 另有 930 筆交易，整體 turnover 很高

### 3. 空倉機制不完整
- 部分月份空倉候選為零（Sharpe 閾值 < -0.3 過嚴或幣種全漲）
- 空倉未考慮融資費率（Funding Rate），永續合約空倉有額外成本

### 4. ATR Trailing Stop 參數
- ATR multiplier = 2.5 在快速市場可能保護不足
- 現版本只在月度換倉時重置 trailing stop，若 stop 提前觸發後當月不再進場

### 5. 極短歷史幣種污染
- USD1, RLSD, EDEN, ONDO 等成立不足一年，在宇宙內但歷史極短
- Walk-Forward 對這些幣的早期 Sharpe 計算可能不穩定

## 下一步改進方向

1. **修正 Survivorship Bias**
   - 改用固定宇宙：只選 2019 年底前已上市的幣（BTC, ETH, XRP, BNB, LTC, BCH, ADA, LINK, ZEC, DOGE 等）
   - 或分層：大市值穩定幣種 + 小部分新興幣種

2. **增加 Funding Rate 成本**
   - 空倉加上永續合約 Funding Rate 成本（歷史平均約 0.01%/8h）

3. **改進短倉選股邏輯**
   - 引入動量 Z-score 篩選，確保短倉候選有穩定下行趨勢

4. **參數敏感性分析**
   - 測試不同 ROC 窗口（10/15/20/30）
   - ATR multiplier (2.0/2.5/3.0)
   - Sharpe 閾值 (1.0/1.3/1.5)

5. **Out-of-Sample 測試**
   - 訓練期：2020-2023；測試期：2024-2026
   - 目前是完整回測，無法確認 OOS 表現

6. **加入最大回撤硬止損**
   - 組合層面：若月度回撤超過 -15% 全部平倉
