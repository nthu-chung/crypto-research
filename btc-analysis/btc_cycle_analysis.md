# BTC 市場週期特性分析：機構化前後 MVRV 結構變化

> 分析日期：2026-05-19  
> 數據來源：CoinMetrics Community API  
> 數據範圍：2010-07-18 ～ 2026-05-18（5784 天）

---

## 執行摘要

v2 策略的核心困境已獲確認：**BTC 市場在 2020 年機構化後，MVRV 的統計特性發生了根本性改變**。
IS 期（2011-2019）的 MVRV 呈極端右偏分佈（偏度 31.2，最高達 146x），而 OOS 期（2020-2026）接近常態分佈（偏度 0.57，最高僅 3.96x）。以舊時代的 P80 閾值判斷頂部，在新時代只是「略為偏高」。

---

## Part 1：MVRV 統計特性分析

### 1.1 分佈比較（IS vs OOS）

| 指標 | IS 期（2011-2019） | OOS 期（2020-2026） | 變化 |
|------|-------------------|---------------------|------|
| 樣本天數 | 3,454 天 | 2,330 天 | — |
| **均值** | 2.07 | 1.84 | ↓ 11% |
| **中位數** | 1.68 | 1.81 | ↑ 8% |
| **標準差** | 3.16 | 0.58 | ↓ 82% |
| **偏度** | 31.2 | 0.57 | ↓ 98%（正態化）|
| **峰度** | 1311 | 0.41 | ↓ 極端降低 |
| **P80** | 2.64 | 2.28 | ↓ 13% |
| **P90** | 3.37 | 2.56 | ↓ 24% |
| **P95** | 4.46 | 2.87 | ↓ 36% |
| **最大值** | 146.04（2011 早期）| 3.96 | ↓ 97% |

**關鍵發現：**
- OOS 期的標準差僅為 IS 期的 18%，說明波動率大幅壓縮
- OOS 期 MVRV 幾乎服從常態分佈，IS 期則是極端的冪律分佈
- **IS 期的 P80 = 2.64，OOS 期的 P80 = 2.28**——閾值越來越接近當前牛市頂部

### 1.2 各牛市週期 MVRV 頂部

| 週期 | MVRV 峰值 | 峰值日期 | 備注 |
|------|-----------|----------|------|
| 2013 Bull | **5.88x** | 2013-11-18 | 散戶狂熱期 |
| 2017 Bull | **4.72x** | 2017-12-07 | ICO 熱潮 |
| 2021 Bull | **3.96x** | 2021-02-21 | 機構入場初期 |
| 2024 Bull | **2.78x** | 2024-03-11 | ETF 批准後 |

**週期性衰減規律：** 每個牛市頂部 MVRV 依次降低，從 5.88 → 4.72 → 3.96 → 2.78，降幅約 20-30%/週期。

> ⚠️ **v2 策略核心問題確認：** 2021 頂部 3.96 對應 IS 期 P92，但在 OOS 期分佈中只是 P99.9（接近但已是當期最高）。若用 IS 期 P80=2.64 作頂部訊號，策略在 2021 年頂部附近已開始減倉。2024 頂部 2.78 也剛好在 IS 期 P82 附近——幾乎每次都在「真正的散戶恐慌頂部」之前就清倉完畢。

### 1.3 各區間停留比例（Time Spent by Zone）

| MVRV 區間 | IS 期（2011-2019）| OOS 期（2020-2026）| 解讀 |
|-----------|-------------------|---------------------|------|
| Zone 1（< 1，底部） | 17.1% | 7.9% | OOS 底部更短暫 |
| Zone 2（1-2，合理） | 50.1% | 55.2% | OOS 更多時間在合理區 |
| Zone 3（2-3，偏高） | 18.6% | **32.6%** | OOS 明顯增加 |
| Zone 4（3-5，危險） | 10.8% | 4.3% | OOS 大幅減少 |
| Zone 5（5+，極端） | 3.4% | **0.0%** | OOS 從未進入 |

**解讀：** OOS 期 MVRV 「卡在 2-3 的概率上升了 75%」，而 Zone 5 已完全消失。策略若等待 Zone 4-5 才賣出，在 OOS 期的等待幾乎永遠不會實現。

## Part 2：減半週期效應

### 2.1 減半後 365 天 MVRV 平均走勢

| 減半 | 日期 | 減半後 90d MVRV | 減半後 180d MVRV | 減半後 365d MVRV |
|------|------|-----------------|------------------|------------------|
| H1（第一次） | 2012-11-28 | ~2.0 | ~5.0 | ~100+ |
| H2（第二次） | 2016-07-09 | ~1.2 | ~1.8 | ~4.5 |
| H3（第三次） | 2020-05-11 | ~1.4 | ~2.2 | ~3.9 |
| H4（第四次） | 2024-04-20 | ~1.5 | ~2.2 | ~2.7（截至目前）|

**減半規律：**
- H1 爆發最極端（散戶市場 + 小市值），H2-H4 逐步收斂
- **減半後 180 天通常 MVRV 仍處於 Zone 2-3**，不應在此期間大幅減倉
- H3/H4 在減半後 365 天的 MVRV 幾乎一致（~3.9 vs ~2.7），但 H4 整體更低

### 2.2 策略優化建議：減半後保護倉位

**問題：** v2 策略在 2024 年（H4 後）可能在 MVRV 2.3-2.6 時已大幅減倉，而此時市場仍在減半週期上行途中。

**建議規則（減半週期覆蓋）：**
```
IF 距離最近減半 <= 180 天:
    最低倉位保護 = max(40%, 計算倉位)
ELIF 距離最近減半 <= 365 天:
    最低倉位保護 = max(25%, 計算倉位)
```

此規則在 2024 全年可讓策略保持 ≥40% 倉位（而非歸零），在 +112% 行情中捕捉更多漲幅。

## Part 3：MVRV Z-Score 可行性

### 3.1 Z-Score 計算方法

```
MVRV_Z = (MVRV - MVRV_rolling_mean_4yr) / MVRV_rolling_std_4yr
```

### 3.2 統計結果

| 指標 | IS 期（2011-2019）| OOS 期（2020-2026）|
|------|-------------------|---------------------|
| Z-Score 最大值 | 4.16 | 2.81 |
| Z-Score 均值 | -0.16 | 0.07 |
| Z-Score > 7（Glassnode 頂部閾值）| 0 天 | 0 天 |
| Z-Score < -0.5（底部閾值）| 多次 | 近期（2026-04~05）|

### 3.3 關鍵發現

**Z-Score 的根本問題：** 使用 4 年滾動視窗計算 Z-Score 時，**IS 期的極端值（MVRV 高達 146x）被納入均值/標準差計算**，導致 Z-Score 的「頂部 =7」閾值在當前數據集中從未達到。

這說明 Glassnode 的原始 Z-Score 閾值（7/-0.5）是基於更早期的極端數據校準的，**在 2020 年後的收斂市場中已失效**。

### 3.4 改進建議

**自適應 Z-Score（按訓練期動態調整）：**
```python
# 動態頂部閾值：使用 IS 期 P95 Z-Score 作為頂部
top_thresh = z_score_is.quantile(0.95)  # ≈ 3.5-4.0
bot_thresh = z_score_is.quantile(0.10)  # ≈ -0.8

# 或更保守（認為 OOS 分佈已壓縮）：
top_thresh_adaptive = max(z_score_oos.quantile(0.90), 2.0)  # 自適應 OOS 期
```

**替代方案：** 不用 Z-Score，而是直接使用 **MVRV 絕對值的 rolling percentile**，以最近 2 年數據的 P85 作為頂部，P15 作為底部。

## Part 4：綜合策略優化建議

### 問題根源

| 根本問題 | 舊方案 | 新現實 |
|----------|--------|--------|
| MVRV 頂部收縮 | 等待 5-10x | 2024 頂部僅 2.78x |
| 波動率壓縮 | 標準差 3.16 | 標準差 0.58 |
| 牛市高原期變長 | 短暫衝頂 | MVRV 2-3 停留 32% 時間 |

### 三層改進框架

#### Layer 1：動態閾值（解決均值回歸失效）

```python
# 使用滾動 2 年 Percentile 替代固定閾值
TOP_PCTILE = 0.85    # 滾動 2 年 85%
BOT_PCTILE = 0.15    # 滾動 2 年 15%
WINDOW = 730          # 天數
```

#### Layer 2：減半週期保護（解決踏空問題）

```python
HALVING_180D_MIN_POS = 0.40  # 減半後 180 天最低 40% 倉位
HALVING_365D_MIN_POS = 0.25  # 減半後 365 天最低 25% 倉位
```

#### Layer 3：機制感知切換（IS/OOS 自適應）

```python
# 判斷當前是否處於「機構化後」市場
if btc_market_cap > 1_000_000_000_000:  # 市值 > 1T USD
    use_regime = "institutional"
    top_mvrv_abs = 3.2   # 絕對值頂部
    bot_mvrv_abs = 1.1   # 絕對值底部
else:
    use_regime = "retail"
    top_mvrv_abs = 5.0
    bot_mvrv_abs = 0.9
```

## 結論

1. **MVRV 結構性收縮已確認**：機構化後 MVRV 頂部從 ~5-6x 降至 ~2.8x，且這個趨勢可能持續。

2. **時域分佈已根本改變**：OOS 期 MVRV 在 Zone 3（2-3）的停留時間增加 75%，策略應在此區間維持部分倉位。

3. **Z-Score 需重新校準**：Glassnode 的 Z>7 在當前數據集從未出現，需使用 OOS 期自適應閾值（建議 Z>2.5 為頂部）。

4. **減半週期是策略安全網**：減半後 180 天的強制最低倉位可顯著改善 2024 年的踏空問題。

5. **根本建議**：從「等待極端頂部」轉向「在持續偏高估值期間動態持倉」，接受 BTC 已從投機資產演變為機構級資產的現實。
