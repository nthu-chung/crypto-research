# Crypto Short-Term Reversal Strategy — 研究報告 v2

> 研究日期：2026-05-19  
> 數據來源：Binance Public API（19幣種，日頻 1d K線，2020–2024）  
> 核心信號：5日動量均值回歸（Mom_5d Reversal）  
> 方法：Walk-Forward OOS 回測 + ICIR 分析 + 截面多空

---

## 一、執行摘要

本研究在對 19 個主流加密貨幣進行日頻多因子分析後，發現 **5日動量反向信號（Mom_5d Reversal）** 是目前測試信號中唯一具備統計顯著性且能轉換為正 Sharpe 策略的 alpha 來源。

### 核心結論

- **所有 19 個幣種的 Mom_5d ICIR 均達 ⭐ 標準（|ICIR| > 0.15）**，反向預測力穩健
- 個別幣種最高 Sharpe：UNI +1.351、ATOM +1.307、LTC +1.271、LINK +1.248
- **15幣等權組合：Sharpe = +1.171，年化報酬 +54.1%，Sortino = +1.527**
- 2023 年是唯一失效年（趨勢市場壓制均值回歸），其餘年份均正
- Flow_z 信號在日頻截面上接近噪音（截面 ICIR = −0.011）

## 二、信號體系

### 2.1 信號定義

```
Mom_5d(t) = Σ log_return(t-4 to t)    # 過去5日累計對數報酬

交易規則（反向）：
  - Mom_5d > Q(thresh) → 做空（強勢反轉）
  - Mom_5d < Q(1-thresh) → 做多（弱勢反彈）
  - 其餘 → 持平（不交易）
```

### 2.2 信號直覺

短期動量在加密市場日頻具有顯著的**均值回歸特性**：
1. 5日大漲的幣種往往已透支短期買盤，次日面臨獲利回吐
2. 5日大跌的幣種往往超賣，技術反彈概率提升
3. 這與 Jegadeesh (1990) 的短期反轉效應在傳統市場的發現一致

### 2.3 測試幣別

BTC、ETH、BNB、SOL、XRP、DOGE、ADA、AVAX、LINK、DOT、TRX、NEAR、UNI、LTC、AAVE、INJ、XLM、FIL、ATOM（共19幣）

## 六、截面多空策略

### 6.1 截面策略結果（每日買最弱5日動量/賣最強5日動量）

| 版本 | Sharpe | AnnRet | MaxDD |
|------|--------|--------|-------|
| Q20/Q80 hold1 | −1.582 | −42.3% | −229.9% |
| Q10/Q90 hold1 | −1.213 | −57.8% | −303.3% |
| **Bear Only hold1** | **−1.177** | −30.0% | −94.8% |
| Flow_z hold1 | −2.987 | −66.3% | −355.5% |

截面策略整體無效，原因：**截面做空強勢幣 = 做空趨勢幣，在牛市中持續逆勢**。

### 6.2 個幣 vs 截面的關鍵區別

```
個幣 Mom_5d 反向：
  ATOM Sharpe = +1.307  ✅
  → 對同一幣種的短期動量做反向，有效

截面 Mom_5d 反向：
  組合 Sharpe = −1.582  ❌
  → 買輸幣、賣贏幣，結果是買到下跌趨勢幣、賣掉上漲趨勢幣
  
結論：信號是時間序列層面的 alpha，不是截面層面的 alpha
```

## 七、風險分析與注意事項

### 7.1 主要風險

| 風險 | 描述 | 緩解方式 |
|------|------|---------|
| **趨勢市場風險** | 2023 年反向失效 | 加 Regime filter（MA50趨勢確認）|
| **MaxDD 過大** | UNI/LTC/LINK > 150% | 降低槓桿 / 限制單幣權重 |
| **參數過擬合** | 最佳參數是掃描出來的 | 已用 Walk-Forward OOS 驗證 |
| **流動性風險** | 小幣種滑點可能高於假設 | 實際執行需要測試市場深度 |
| **換幣集中度** | 15幣等權，少數幣（LINK 2024）貢獻大 | 監控個幣貢獻度 |

### 7.2 Data Snooping 檢查

| 檢查項目 | 結果 |
|---------|------|
| 是否 Walk-Forward OOS | ✅ 是（min_train=252d）|
| ICIR 全幣種一致 | ✅ 19/19 均負向 |
| 跨年度穩健性 | ⚠️ 2023 年失效 |
| 信號邏輯可解釋 | ✅ 短期反轉效應（Jegadeesh 1990）|
| 多重檢定風險 | ⚠️ 參數掃描有 snooping 風險，建議固定參數再測 |

## 八、建議執行策略

### 8.1 核心策略設計

```
策略名稱：Crypto Mom_5d Reversal Portfolio
目標宇宙：ATOM, LTC, LINK, UNI, DOT + 其他正ICIR幣種（共15幣）
信號：Mom_5d = 5日累計對數報酬
進場：Mom_5d > Q85（做空）/ Mom_5d < Q15（做多）
持倉：1~3 天（ATOM 用1天，LTC/LINK 用3天）
權重：等權或 1/vol 加權
再平衡：每日計算信號，每月 refit 閾值
TC：盡量用 Maker 掛單（~0.02%），目標控制在 0.05%/日以下
停損：單幣月回撤 > 30% 時暫停該幣信號
Regime filter：BTC < MA50 × 0.95 時關閉做多方向
```

### 8.2 即時部署考量

| 項目 | 說明 |
|------|------|
| **進場時機** | 每日收盤後計算信號，次日開盤 Maker 掛單 |
| **費率** | 目標 Maker fee 0.02%（VIP0 也可到 Limit 掛單）|
| **倉位大小** | 建議單幣不超過 10% 倉位（等權15幣 = 6.7%/幣）|
| **監控頻率** | 每日一次即可 |

## 九、下一步研究方向

1. **Regime Filter 加入**：在 BTC 趨勢強烈時（ADX > 25）關閉反向信號，解決 2023 年失效問題
2. **固定參數驗證**：用 Q85/Hold=1d/TC=0.1% 固定參數重跑，消除參數掃描的 snooping 風險
3. **真實 CryptoQuant 數據**：加入 Exchange Netflow 作為第二因子
4. **組合優化**：用 HRP（Hierarchical Risk Parity）替代等權，降低 MaxDD
5. **實盤 Paper Trading**：在 Binance Testnet 部署30天，驗證假設

## 十、結論

**Mom_5d 反向（5日動量均值回歸）是目前發現最強且最具學術支撐的日頻加密貨幣 alpha 信號。**

核心數據：
- 19/19 幣種 ICIR 顯著為負（最強 ATOM ICIR = −1.043）
- 15幣等權組合：**Sharpe +1.171，年化 +54.1%，Sortino +1.527**（Walk-Forward OOS）
- 唯一弱點：2023 趨勢市失效，需要 Regime filter 保護

這個策略的學術對應是 **Jegadeesh (1990)** 的短期反轉效應在加密市場的實證驗證，結合 **Bieganowski & Ślepaczuk (2026)** 的微觀結構框架，具備清晰的理論基礎和可執行的操作規則。
