## 核心邏輯

本策略以 **MVRV（市值/已實現市值）比率**作為 BTC 市場估值核心，結合多層次技術指標進行倉位動態管理，並於特定估值區間搭配選擇權策略強化報酬或對沖風險。

### 策略架構

```
Layer 1: MVRV 區間分類（估值框架）
    MVRV < 1.0    → 極度低估區（Zone 5）→ 滿倉 100%
    1.0–1.5       → 低估區（Zone 4）    → 75–80%
    1.5–2.5       → 合理區（Zone 3）    → 30–60%（依技術條件）
    2.5–3.7       → 高估區（Zone 2）    → 20%
    > 3.7         → 極度高估（Zone 1）  → 0%（全空倉）

Layer 2: 技術指標濾網
    SMA200        → 趨勢確認（多頭/空頭環境）
    RSI(14)       → 動能確認（超賣補倉 / 超買減倉）
    MVRV 30日MA   → 平滑訊號、降低假突破

Layer 3: 動態倉位調整規則
    Zone 3 + 價格 > SMA200 + RSI > 50 → 60%
    Zone 3 + 價格 > SMA200             → 50%
    Zone 3 + 價格 < SMA200             → 30%（防守）

Layer 4: 選擇權應用
    Zone 5 (MVRV<1.0): 賣現金擔保 Put（收取權利金、低位建倉）
    Zone 3 (合理區):   賣 Covered Call（持倉增益）
    Zone 1 (MVRV>3.7): 買保護性 Put（對沖極端估值尾部風險）
```

### 訊號建構注意事項
- **無前瞻偏差（No Look-ahead Bias）**：訊號使用 T-1 日的 MVRV 值，T 日開盤執行
- 僅當倉位目標變化 > 5% 時才觸發交易，降低摩擦成本
- 每筆交易額外過濾：Delta ≤ 1% of portfolio 的微量變動不執行

    target = 0.80 if price > SMA200 else 0.75

    if price > SMA200 and RSI > 50: target = 0.60

# 執行觸發：|新目標 - 舊目標| > 5% 且 delta > 1% portfolio

## 選擇權應用

### 策略框架
基於 Black-Scholes 簡化模型（σ_BTC ≈ 70% 年化波動率）

| MVRV 區間 | 選擇權策略 | 目的 |
|-----------|-----------|------|
| < 1.0（Zone 5） | 賣 OTM Put（K ≈ 現價 × 85%） | 收取權利金，如被行使則低位建倉 |
| 1.5–2.5（Zone 3） | 賣 Covered Call（K ≈ 現價 × 110%） | 持倉期間增益，每月 ~4.3% premium |
| > 3.7（Zone 1） | 買保護性 Put（K ≈ 現價 × 85%） | 對沖極端高估的崩盤風險 |

### 當前估值快照（2026-05-18）
- BTC 現價：~$77,000，MVRV ≈ 1.42（Zone 4，低估區）
- **建議操作：**
  - 維持 75–80% BTC 多頭倉位
  - 可考慮賣 OTM Covered Call（K = $85,000, 30天期）
  - 預估權利金：$3,338 / BTC ≈ 4.3% 月報酬

### 選擇權模型局限
- BS 簡化模型未考慮：實際隱含波動率 smile/skew、流動性折扣、Deribit 實際報價
- 加密選擇權實際 IV 通常比歷史波動率高出 20–40%，上述估值為保守下限
- 實際執行需查詢 Deribit 或 Binance Options 當前 IV 及 bid/ask
